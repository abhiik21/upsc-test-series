How to analyse a UPSC mock test after you finish it

12 min read · Test Analysis

A mock test is useful only when the attempt is converted into learning. The objective of post-test analysis is to identify which mistakes were knowledge gaps, which came from poor interpretation, and which resulted from avoidable decision-making.

1. Start with the attempt pattern

Record attempted, correct, incorrect and unattempted questions. Look at accuracy alongside score so that improvements do not come only from attempting more questions.

2. Review every incorrect answer

Classify each mistake: knowledge gap, conceptual confusion, misreading, elimination error or rushed decision. The category determines what you should revise.

3. Identify topic-level gaps

Map mistakes back to subjects and topics. A recurring weak topic is a stronger signal than a single difficult question.

4. Convert mistakes into action

  • Revise the relevant concept.
  • Save the question or explanation.
  • Add important mistakes to the Mistake Notebook.
  • Practise a short focused set before the next full-length test.
